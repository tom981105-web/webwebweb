자유게시판 카페형 개편

자유게시판을 카테고리 중심 게시판으로 다시 구성하고, 목록과 본문 전환 흐름을 카페처럼 읽기 쉽게 정리했습니다.

  • 카테고리 1~4 기반으로 게시판을 분리하고, 글 작성 시 카테고리를 선택할 수 있게 했습니다.
  • 게시글을 누르면 모달이 아니라 같은 화면 안에서 본문이 열리도록 바꿨습니다.
  • 본문 상단 정보바, 목록 상단 고정 공지, 이전글/다음글 버튼을 추가했습니다.
  • 본문 아래에 같은 카테고리의 다른 게시글 제목 5개를 바로 볼 수 있게 넣었습니다.

저장 구조 정리와 화면 복구

백업 상태를 기준으로 로그인, 관리자 흐름, 게시판, AI, 산행기 페이지를 다시 점검하고 끊긴 작업을 이어서 복구했습니다.

  • 관리자 페이지 배너 편집 흐름과 위치 조절 UI를 메인 페이지 기준에 맞춰 정리했습니다.
  • 기존에 저장돼 있던 `/uploads/...` 배너 경로도 메인에서 다시 보이도록 호환 처리를 추가했습니다.
  • 게시판 댓글에 관리자 답글을 달 수 있도록 마지막으로 중단돼 있던 로직을 마무리했습니다.

AI와 산행기 UI 재정비

개별 페이지가 따로 노는 느낌을 줄이고, 톤과 정보 밀도를 맞춰 전체 경험이 자연스럽게 이어지도록 조정했습니다.

  • AI 페이지를 카드형 레이아웃으로 정리하고 프롬프트 보관 영역도 같은 분위기로 통일했습니다.
  • 추천 AI 데이터 구조를 보정해 기본 프롬프트와 편집 화면이 동일하게 동작하도록 손봤습니다.
  • 산행기 페이지의 깨진 문구와 카드, 상세 모달 스타일을 복구하고 메인과 이어지는 밝은 톤으로 정리했습니다.

확인 메모

운영 중 다시 점검하면 좋은 부분도 함께 적어 둡니다.

  • 외부 지도 타일과 외부 GeoJSON처럼 네트워크 의존성이 큰 구간은 장기적으로 대체 소스를 두는 편이 안전합니다.
  • 브라우저 로컬 저장 방식 특성상 이미지가 많아지면 저장 용량 한계에 가까워질 수 있습니다.
  • 공통 상단 유틸과 주요 페이지 톤은 맞췄고, 관리자 페이지는 현재 관리자 전용 구조를 유지하고 있습니다.
